# 译制配音配方

**核心纪律：时间轴来自原片，不来自译文。** 先转写拿区间，再让译文去贴合区间，绝不让画面去等配音。

## 阶段序列

1. **析**（必须基于原片）— `mont_transcribe_audio` 出带时间戳的字幕；
   需要分镜参照时 `mont_video_analyze` 拆镜。无原片时不要开工。
2. **问**（一次问清）— 目标语言、语气（新闻播报 / 口语化 / 广告腔）、是否保留原声底、
   字幕是烧入还是软轨、是否保留原版 BGM。
3. **译**（按窗口折算）— 每条字幕先算可容纳字数（`mont_speech_duration` + `windowSec`），
   超窗缩句或拆条；术语统一走 `mont_terms_set`（品牌名、专有名词的读法）。
   译完跑 `mont_srt_lint`：单行 ≤16 字、≤17 字/秒、单条 ≥0.83s。
4. **声**（分轨生成）— 按条生成译文配音，`mont_audio_sync` 用原片语音区间做锚对齐；
   不要整段铺一条 TTS 再硬拉时长。
5. **配**（混音与字幕）— `mont_audio_mix`：译文配音为主，原声压到 -18 dB 以下做底；
   `mont_subtitle_format`（ass/srt）→ `mont_video_subtitle`。

## 门禁

- 原文未转写不开译。
- 每条字幕超窗必须先缩句，禁止靠加速 TTS 硬塞。
- 术语表未确认前不生成配音（品牌读音错一次，全片返工）。
- 字幕与配音时长偏差 > 0.3s 的条目必须回修。

## 平台差异

| 场景 | 字幕 | 混音 |
|---|---|---|
| 短视频译制 | 烧入硬字幕（平台常静音播放） | 保留原 BGM，压原声 |
| 长片译制 | 软轨可选 | 原声轨保留，译文轨独立 |
| 广告译制 | 烧入 + 双语可选 | 原配乐不动 |
