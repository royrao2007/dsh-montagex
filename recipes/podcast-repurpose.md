# 播客改造配方

**核心纪律：这是剪辑，不是生成。** 切片的价值在于"原话够硬"，画面只是承载；不要为切片去生成不存在的场景。

## 阶段序列

1. **析**（转写）— `mont_transcribe_audio` 出带时间戳字幕；
   有视频源时同跑 `mont_video_analyze` 拿分镜边界，切片切点优先落在镜头边界上。
2. **选**（排名）— `mont_clip_rank` 用脚本/关键词对每条字幕打分，给出候选排序；
   人工只做"选哪条"，不做"逐条听"。
3. **问**（一次问清）— 出几条、单条时长、是否加字幕/波形/口播人像画中画、平台画幅。
4. **稿**（切片稿）— 每条切片写：钩子句（前 3 秒）+ 观点句 + 收尾句。
   钩子必须是原话里的硬句，不要用旁白补。
5. **剪**（确定性）— `mont_subtitle_cut` 按字幕窗口切段；需要拼接多条时 `mont_video_process` + `mont_video_concat`；
   去掉停顿用 `mont_smart_cut`（LLM 精剪走本地匹配，不调生成模型）。
6. **包**（交付）— 字幕烧入 `mont_video_subtitle`；封面与多规格 `mont_media_package`。

## 门禁

- 每条切片必须有可独立的钩子句，没有就不切。
- 切点不得切断一句话中间（以字幕条边界为准）。
- 字幕按句切，单行 ≤16 字；语速 > 17 字/秒的条目回修。
- 出片数量与问清的条数一致，不多给"赠品"。

## 质量判据

| 判据 | 标准 |
|---|---|
| 3 秒钩子 | 前 3 秒出现结论或冲突，不是寒暄 |
| 完整性 | 一个切片只讲一件事，首尾自洽 |
| 画面稳定 | 切片内画面不跳变；跳变点与句号对齐 |
| 音量一致 | 多切片之间响度差 ≤ 2 LU |
